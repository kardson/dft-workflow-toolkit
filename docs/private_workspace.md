# 私有工作区结构

公开工具仓库与研究工作区分开维护。以下名称是示意目录，真实内容不进入公开 Git 历史。

```text
private-research/
  plan/          研究问题、想法与方法规格
  literature/    文献、批注、提取文本与索引
  models/        结构与模型谱系
  runs/          输入、输出、重启与执行记录
  analysis/      结果、图表和科学解释
  manuscripts/   论文、汇报与评审材料
  local-config/  私有环境与连接配置
```

工具以明确路径读取使用者指定的输入，并把结果写入私有工作区。公开仓库仅保存通用代码、空白记录和合成测试。不要把上述目录通过子模块、软链接或目录联接放入公开仓库。

私有工作区可以单独使用本地 Git 或访问受限的远端备份；是否上传、上传到何处，由拥有者另行决定。不能通过把公开仓库后来改成私有来追回已经公开的数据。
