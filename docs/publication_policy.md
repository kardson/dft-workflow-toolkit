# 公开边界

## 可公开

通用协作规则、目录组织方法、明确授权与交接流程、通用软件源码、空白模板，以及从零构造的测试数据。

## 保密

真实文献文件与选读索引、论文与草稿、研究想法和假设、材料与模型来源、具体参数与科学选择、计算输入输出与派生结果、真实算例记录、工作站身份及连接信息。删除文件正文后留下的标题、目录名、编号或注释也可能泄露研究方向。

授权赝势、商业软件和未经确认可再分发的第三方资料不能随工具公开。

## 发布操作

1. 使用独立公开目录和独立 Git 历史。
2. 逐文件审阅，维护明确白名单。新增文件默认未批准。
3. 核对文档、源码常量、测试夹具、模板、配置、Git index 和历史；不要只看当前目录。
4. 运行保密检查并人工确认研究思想与方法边界。
5. 确定代码权属、项目许可证、仓库名称、发布账号和可见性。
6. 仅从这个独立仓库执行首次提交与发布；不合并私有仓库历史。

`.gitignore` 是辅助防护；已跟踪文件与旧提交不会因添加忽略规则而自动消失。发布后也应持续检查每次差异、提交说明、Issue、PR、Actions 日志与附件。

依据：[GitHub 忽略文件说明](https://docs.github.com/en/get-started/git-basics/ignoring-files)、[GitHub 敏感数据处理说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository)。
